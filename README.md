## 🛡️ Featured Final Year Project

### Human-in-the-Loop Intrusion Detection Dashboard

**CSIT321 | October 2026 – March 2027**

🚧 **Status: In Development**

A web-based security monitoring dashboard designed to process Suricata IDS alerts, support analyst feedback, and adapt alert prioritisation.

**Planned Features**
- Suricata EVE JSON alert integration
- Security alert monitoring
- Analyst feedback and investigation notes
- Risk-based alert scoring
- Similar alert identification
- Adaptive alert prioritisation
- Explainable alert priority decisions
- Alert analytics and visualisations

**Advanced Features Under Research**
- Machine Learning-Assisted Alert Prioritisation
- Active Learning
- Online / Incremental Learning with River
- Explainable AI using SHAP

**Proposed FYP Tech Stack**
- Frontend: React.js
- Backend: Python / FastAPI
- Frontend Tooling: Node.js / npm
- Database: SQLite / PostgreSQL
- Intrusion Detection: Suricata IDS
- Deployment: Vercel
